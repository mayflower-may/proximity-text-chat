# Changelog

## 3.0.0

- New module id `proximity-text-chat-continued`. Settings and message tiers are imported from the original `proximity-text-chat`; the module stays idle while the original is active.
- Foundry VTT v13 and v14 support.
- Whisper / talk / shout voice tiers with a selector button in the chat input.
- Tier styling for chat bubbles and chat log messages.
- Whisper listener list.
- Optional: walls block speech, roll message distance, deafened and silenced conditions, emote styling.
- Messages heard on arrival are remembered per browser.
- Minimum bubble duration, shout bubble duration, bubble font and colour.
- Disguise, Polymorph and Wild Shape token handling (dnd5e); duplicate or hidden copies of a character's token no longer break hearing range.
- Monk's TokenBar roll request visibility.
- Turkish translation.
